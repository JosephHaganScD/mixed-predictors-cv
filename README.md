## Overview

This repository contains all code and summary-level simulation outputs needed to reproduce the tables, figures, and supplementary material reported in the manuscript above. The study examines how naive cross-validation (CV) inflates apparent discrimination in clinical prediction models when predictors include both fixed (time-invariant) covariates and repeated longitudinal measurements, and demonstrates that subject-level CV eliminates this inflation.

## Reproducing the simulation results

The iteration-level simulation output (`sim_results_v8.csv`, 567,000 rows, approximately 208 MB) is not included in this repository because it exceeds GitHub's file size limit. It can be regenerated by running `run_simulation.R` with the settings documented in that script. All summary-level outputs derived from it are included above and are sufficient to reproduce every table and figure in the manuscript.

**Estimated run time:** approximately 18 to 24 hours on a single machine using parallel execution across available cores. Results are checkpointed; interrupted runs resume from the last completed condition.

**Required R packages:**

```r
# Core simulation
install.packages(c("glmnet", "xgboost", "pROC", "parallel", "doParallel", "foreach"))

# Supplementary analyses and figures
install.packages(c("ggplot2", "dplyr", "tidyr", "tibble", "patchwork", "scales"))

# Supplementary tables
install.packages(c("officer", "flextable"))

# cawCV package (subject-level and LOCO CV implementations)
# install from Zenodo: https://doi.org/10.5281/zenodo.20789601
```

**R version used:** R 4.6.1 (platform: x86_64-w64-mingw32/x64, Windows)

**Reproducing the figures:**  
Figures 2 and 3 are generated from `sim_summary_v8.csv` and `categorical_results.csv` respectively, using `9-10-26_simmm_results_graphs_revised.R`. Figure 4 is generated from the hard-coded empirical values in `figure4_rop_empirical.R`, which are verified against the console output files above.

**Reproducing the supplementary tables:**  
Run `supplementary_tables_S1_S10.R`. Tables S4 and S10 additionally require `sim_results_v8.csv` (see above); all other tables use the summary-level CSV files included in this repository.

## Empirical data availability

The retinopathy of prematurity cohort analyzed in Section 2.6 and Section 3.5 of the manuscript consists of de-identified patient-level data from a previously published retrospective study (Srivatsa et al., *Journal of Pediatrics*, 2022; DOI: 10.1016/j.jpeds.2022.03.057). The data were used with written permission from the original principal investigator and data custodian. Because the dataset consists of de-identified patient-level clinical data, it cannot be shared publicly without authorization from the original investigator and any applicable institutional review. Requests for access should be directed to the original data custodian.

The empirical analysis script (`rop_mixed_predictor_analysis.R`) and its console output files are included to document the analysis exactly as performed. Output values are additionally hard-coded in `figure4_rop_empirical.R` and `supplementary_tables_S1_S10.R` for reproducibility of the figures and tables without requiring the raw data.
