## Overview

This repository contains the code and summary-level simulation outputs used to produce the tables, figures, and supplementary material reported in the manuscript above. The iteration-level simulation results and the patient-level clinical data are not stored here (see "Reproducing the simulation results" and "Empirical data availability" below). The study examines how naive cross-validation (CV) inflates apparent discrimination in clinical prediction models when predictors include both fixed (time-invariant) covariates and repeated longitudinal measurements, and demonstrates that subject-level CV eliminates this inflation.

## Reproducing the simulation results

The iteration-level simulation output (`sim_results_v8.csv`, 567,000 rows, about 200 MB) is not included in this repository because it exceeds GitHub's file size limit. It is deposited as a separate Zenodo dataset (DOI: [FILL: Zenodo DOI after minting]). To run the scripts that need it, download the file and place it in the repository root, or set `SIM_DIR` in `supplementary_tables_S1_S10.R`. The file can also be regenerated by running `run_simulation.R` with the settings documented in that script. All summary-level outputs derived from it are included above and are sufficient to reproduce every table and figure in the main manuscript. Supplementary Tables S4, S10, and S11 additionally require the iteration-level file.

**Estimated run time:** approximately 18 to 24 hours on a single machine using parallel execution across available cores. Results are checkpointed; interrupted runs resume from the last completed condition.

**Required R packages:**

```r
# Core simulation
install.packages(c("glmnet", "xgboost", "pROC", "parallel", "doParallel", "foreach"))

# Supplementary analyses and figures
install.packages(c("ggplot2", "dplyr", "tidyr", "tibble", "patchwork", "scales"))

# Supplementary tables
install.packages(c("officer", "flextable", "data.table"))

# cawCV package (subject-level and LOCO CV implementations)
# install from Zenodo: https://doi.org/10.5281/zenodo.20789601
```

**R version used:** R 4.6.1 (platform: x86_64-w64-mingw32/x64, Windows). Supplementary table scripts were run with data.table 1.18.4, flextable 0.9.12, and officer 0.7.5.

**Reproducing the figures:**  
Figures 2 and 3 are generated from `sim_summary_v8.csv` and `categorical_results.csv` respectively, using `9-10-26_simmm_results_graphs_revised.R`. Figure 4 is generated from the hard-coded empirical values in `figure4_rop_empirical.R`, which are verified against the console output files above.

**Reproducing the supplementary tables:**  
Set the working directory to the repository folder, then run:

```r
source("supplementary_tables_S1_S10.R")      # Tables S1 to S10
source("s11_between_iteration_intervals.R")  # Table S11; requires sim_results_v8.csv
```

Tables S4 and S10 require `sim_results_v8.csv`; if that file is absent, the script skips those two tables with a warning and produces all others from the summary-level CSV files included in this repository. Table S9 (Panels A to C) is built from values hard-coded from the empirical console outputs named in the script.

## Empirical data availability

The retinopathy of prematurity cohort analyzed in Section 2.6 and Section 3.5 of the manuscript consists of de-identified patient-level data from a previously published retrospective study (Srivatsa et al., *Journal of Pediatrics*, 2022; DOI: 10.1016/j.jpeds.2022.03.057). The data were used with written permission from the original principal investigator and data custodian. Because the dataset consists of de-identified patient-level clinical data, it cannot be shared publicly without authorization from the original investigator and any applicable institutional review. Requests for access should be directed to the original data custodian, Dr. Bharath Srivatsa.

The empirical analysis script (`rop_mixed_predictor_analysis.R`) and its console output files are included to document the analysis exactly as performed. Output values are additionally hard-coded in `figure4_rop_empirical.R` and `supplementary_tables_S1_S10.R` for reproducibility of the figures and tables without requiring the raw data.

**Note on sample size in the empirical outputs.** The full-predictor analyses used 100 subjects after complete-case restriction (see "Subjects: 100" in the output), although some header labels in the console files read "n=101". The reduced-predictor (Tier 2) analyses used 101 subjects because they do not require the five-minute Apgar score.
